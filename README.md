# Sales & Revenue Dashboard

Power BI portfolio dashboard for FMCG distribution sales analysis in the Philippines. The dashboard tracks revenue, target attainment, regional contribution, product performance, category gaps, and salesperson performance.

## Dashboard Overview

This project presents an executive-style sales and revenue dashboard built in Power BI. It is designed to help business users quickly understand whether revenue is tracking against target, which regions and product categories drive performance, and which salesperson accounts need attention.

## Key Insights

- Total revenue reached PHP 103.9M.
- Target attainment is 98.0%, indicating near-target performance.
- Luzon contributes the largest revenue share at 55.1%.
- Mindanao is the smallest regional contributor.
- Confectionery and selected salesperson accounts are key watch areas.

## Features

- KPI summary for revenue, target attainment, average monthly revenue, active customers, and inactive accounts
- Period slicer for Full Year, H1 2024, Q1 2024, and Q2 2024
- Monthly revenue vs target trend
- Revenue vs target by region
- Revenue share by region
- Top products by revenue
- Target vs actual by category
- Monthly performance detail table
- Salesperson performance detail with conditional formatting
